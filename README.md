# E-Commerce Data Analysis

## About the Project

This project is an analysis of an e-commerce dataset using Python. The main goal is to understand customer orders, sales performance, product performance, and revenue trends.

I used Python and Pandas for data cleaning and analysis and Matplotlib and Seaborn for visualization.

## What I Analyzed

- Customer orders by country
- Total sales revenue
- Average Order Value (AOV)
- Best-selling products
- Top products by revenue
- Revenue by product category
- Monthly revenue trends
- Key business metrics and insights

## Dataset

The dataset used for this project is the **Online Retail Dataset** from Kaggle.

[Kaggle Dataset](https://www.kaggle.com/datasets/vijayuv/onlineretail)

The dataset contains information such as:

- Invoice number
- Product description
- Quantity
- Invoice date
- Unit price
- Customer ID
- Country
